# Security policy

## Supported versions

Security fixes are provided for the latest tagged release. Pre-1.0 releases may contain API changes, which will be documented in the changelog.

## Reporting a vulnerability

Do not open a public issue. Email `security@vedismm.ru` with the affected version, impact, reproduction steps, and any suggested mitigation. Do not include production tokens or user data. We will acknowledge a complete report within five business days.

The SDK intentionally has no persistent credential storage, telemetry, redirect following, or administrative endpoints.
