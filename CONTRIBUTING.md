# Contributing

1. Discuss externally visible behavior in an issue before a large change.
2. Keep the runtime native PHP and free from generated public APIs.
3. Add a failing test first and preserve exact canonical-operation conformance.
4. Run `composer quality`, `composer validate --strict`, documentation checks, and artifact inspection.
5. Never commit credentials, production payloads, or local absolute paths.

By contributing, you agree that your work is licensed under MIT.
